# 🚀 GitHub Profile Searcher

Uma aplicação web moderna e responsiva que consome a API do GitHub para buscar e exibir informações de usuários em tempo real, utilizando requisições assíncronas (AJAX).

## 📋 Sobre o Projeto

O projeto permite que o utilizador digite um nome de utilizador do GitHub e visualize instantaneamente dados essenciais como:
* **Perfil:** Foto, nome e biografia.
* **Estatísticas:** Número de seguidores e utilizadores seguidos.
* **Repositórios:** Lista dos repositórios públicos com links diretos.

## 🛠️ Tecnologias Utilizadas

* **HTML5 & CSS3:** Estrutura e estilização avançada.
* **JavaScript (ES6+):** Lógica de manipulação do DOM e AJAX (Fetch API).
* **GitHub API:** Fonte oficial dos dados.
* **Design Responsivo:** Interface adaptada para dispositivos móveis e desktop utilizando Flexbox e Grid Systems.

## ⚙️ Funcionalidades Principais

1.  **Consumo de API Dinâmico:** Requisições otimizadas para busca de dados em tempo real.
2.  **Interface Reativa:** Renderização automática de componentes baseada no retorno da API.
3.  **Tratamento de Erros:** Mensagens personalizadas para utilizadores não encontrados ou falhas de ligação.
4.  **Foco em Performance:** Carregamento rápido de imagens e dados via AJAX.
